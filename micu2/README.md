# MICU 2 เวลาเข้า-ออกงาน

ระบบลงเวลาเข้า-ออกงานพยาบาล หอผู้ป่วย MICU 2(240)

เว็บแอปบนมือถือสำหรับพยาบาลลงเวลาเข้า-ออกเวร ข้อมูลบันทึกลง Google Sheets

- เลือกชื่อจากรายชื่อ (เครื่องจะจำชื่อไว้ครั้งต่อไป)
- ตรวจตำแหน่ง GPS ต้องอยู่ในรัศมี 100 เมตรจากหอผู้ป่วย (ตรวจซ้ำที่เซิร์ฟเวอร์)
- 3 เวร: เช้า 08:00–16:00 · บ่าย 16:00–24:00 · ดึก 00:00–08:00
- ใช้เวลาของเซิร์ฟเวอร์ (เวลาประเทศไทย) แก้นาฬิกาในมือถือเพื่อโกงเวลาไม่ได้
- คำนวณ มาสาย / ออกก่อน / ออกหลังเวร / ชั่วโมงทำงาน อัตโนมัติ
- หัวหน้าหอดูข้อมูลใน Google Sheet ได้โดยตรง มีเมนูสร้าง **สรุปรายเดือน** และ **รายงานรายวัน**

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บสำหรับพยาบาล (ไฟล์เดียว) |
| `apps-script/Code.gs` | โค้ดหลังบ้าน วางใน Apps Script ของ Google Sheet |
| `apps-script/appsscript.json` | ตั้งค่าโซนเวลา Asia/Bangkok (ไม่บังคับ) |

## ขั้นตอนติดตั้ง

### 1. สร้าง Google Sheet และ Apps Script
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `ลงเวลา MICU 2(240)`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม วางโค้ดจาก `apps-script/Code.gs` แล้วกดบันทึก
4. เลือกฟังก์ชัน `setup` ด้านบน แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (ครั้งแรกจะเตือน "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจกต์)
5. จะได้ชีต 3 แผ่น: `ตั้งค่า`, `รายชื่อพยาบาล`, `บันทึกเวลา`

### 2. ใส่รายชื่อพยาบาล
ชีต `รายชื่อพยาบาล`: รหัสพนักงาน | ชื่อ-สกุล | ตำแหน่ง | ใช้งาน (ติ๊กถูก)
ลบแถวตัวอย่างออก เมื่อมีคนย้ายออกให้เอาเครื่องหมายถูกในช่อง "ใช้งาน" ออก (ไม่ต้องลบแถว)

### 3. Deploy เป็นเว็บแอป
1. ใน Apps Script กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
2. ประเภท: **เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`
4. นำ URL ไปเชื่อมกับหน้าเว็บตามขั้นตอนที่ 4

> ถ้าแก้โค้ด Code.gs ภายหลัง ต้อง **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมจึงจะใช้โค้ดใหม่

### 4. เผยแพร่หน้าเว็บ
ปัจจุบันเผยแพร่ไว้ที่ **https://micu2-240-attendance.netlify.app/** (Netlify)

**เชื่อมหน้าเว็บกับ Google Sheet ผ่านลิงก์** (ไม่ต้องแก้โค้ด): เปิด
`https://micu2-240-attendance.netlify.app/?api=<URL ที่ลงท้าย /exec>` เครื่องจะจำไว้
ใช้ลิงก์นี้ทำ QR Code ให้พยาบาลสแกน (เปิด `?api=reset` เพื่อล้างค่า)
หรือใส่ URL ใน `API_URL_FIXED` ของ index.html แล้วอัปโหลดใหม่ เพื่อไม่ต้องใช้ ?api=

ทางเลือก: GitHub Pages
GPS ในเบราว์เซอร์ใช้ได้เฉพาะเว็บที่เป็น `https://`
1. GitHub repo → **Settings → Pages** → Source: Deploy from a branch → เลือก branch และโฟลเดอร์ `/ (root)`
2. หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/nursenews/micu2/`
3. ทำ QR Code ของลิงก์นี้ติดที่หอผู้ป่วย หรือให้พยาบาล "เพิ่มลงในหน้าจอหลัก"

### 5. ตั้งพิกัดหอผู้ป่วย
1. เปิดหน้าเว็บด้วยมือถือ **ขณะยืนอยู่ในหอผู้ป่วย MICU 2**
2. กด "พิกัดของเครื่องนี้ (สำหรับผู้ดูแลตั้งค่า)" → **คัดลอกพิกัด** (เช่น `13.756300,100.501800`)
3. ในชีต `ตั้งค่า` ใส่ตัวเลขแรกที่ `LAT` และตัวเลขหลังที่ `LNG`
4. ลองลงเวลาทดสอบ แล้วลบแถวทดสอบในชีต `บันทึกเวลา`

## ค่าที่ปรับได้ในชีต `ตั้งค่า`

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `RADIUS_M` | 100 | รัศมีที่อนุญาต (เมตร) ถ้าในอาคาร GPS คลาดเคลื่อนบ่อยอาจขยายเป็น 150–200 |
| `LATE_GRACE_MIN` | 0 | ผ่อนผันมาสาย (นาที) |
| `OPEN_BEFORE_MIN` | 120 | ลงเวลาเข้าได้ก่อนเริ่มเวรกี่นาที |
| `MAX_ACCURACY_M` | 0 | ปฏิเสธพิกัดที่คลาดเคลื่อนเกินกี่เมตร (0 = ไม่จำกัด) |
| `SHIFT_M / SHIFT_A / SHIFT_N` | 08:00-16:00 ฯลฯ | เวลาเวรเช้า/บ่าย/ดึก |

## สำหรับหัวหน้าหอ
เปิด Google Sheet แล้วใช้เมนู **MICU 2 เวลาเข้า-ออกงาน** (มุมบนขวา)
- **สรุปรายเดือน…** → จำนวนเวรเช้า/บ่าย/ดึก, มาสาย (ครั้ง/นาที), ออกก่อน, ไม่ลงเวลาออก, ชั่วโมงรวม ต่อคน
- **รายงานรายวัน…** → รายชื่อผู้ลงเวลาแยกตามเวรของวันนั้น

ส่งออกเป็น Excel/PDF ได้จาก **ไฟล์ → ดาวน์โหลด** แชร์ Sheet ให้หัวหน้าแบบ "ผู้มีสิทธิ์อ่าน" หรือ "ผู้แก้ไข" ตามต้องการ

## กติกาการลงเวลา
- **วันที่เวร**: เวรดึกของวันที่ 17 คือ 00:00–08:00 ของวันที่ 17 (ลงเวลาเข้า 23:45 ของวันที่ 16 จะนับเป็นเวรดึกวันที่ 17)
- ลงเวลาเข้าซ้ำเวรเดิมในวันเดียวกันไม่ได้
- ลงเวลาออกจะปิดรายการเข้างานล่าสุดที่ยังไม่ได้ลงเวลาออก (ภายใน 20 ชม.)
- **ขึ้นเวรควบ** (เช่น เช้า+บ่าย): ลงเวลาออกเวรเช้า แล้วลงเวลาเข้าเวรบ่ายต่อ
- ลืมลงเวลาออกเกิน 4 ชม. หลังจบเวร → ในสรุปรายเดือนจะนับเป็น "ไม่ลงเวลาออก"

## โหมดทดลอง
ถ้ายังไม่ใส่ `API_URL` หน้าเว็บจะทำงานในโหมดทดลอง เก็บข้อมูลในเครื่องเท่านั้น และถือว่าตำแหน่งปัจจุบันคือหอผู้ป่วย ใช้สำหรับลองหน้าตาก่อนติดตั้งจริง

## ข้อจำกัดที่ควรทราบ
- GPS ในอาคารอาจคลาดเคลื่อน 20–100 เมตร ระบบป้องกันการลงเวลาจากนอกโรงพยาบาลได้ แต่ไม่ได้ยืนยันว่าเป็นตัวบุคคลจริง (ไม่มี PIN/รูปถ่าย) จึงยังเลือกชื่อคนอื่นลงแทนได้หากอยู่ในพื้นที่
- แอปปลอมตำแหน่ง (Fake GPS) บน Android บางตัวอาจหลบการตรวจได้
- ข้อมูลรายบุคคล (เวลา พิกัด) เป็นข้อมูลส่วนบุคคลตาม PDPA ควรจำกัดสิทธิ์การเข้าถึง Google Sheet และแจ้งวัตถุประสงค์การเก็บข้อมูลแก่บุคลากร
